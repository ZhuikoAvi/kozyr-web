# Козырь — веб-версия

Дурак и покер с друзьями без интернета — для iPhone и любых телефонов без приложения.

**Играть:** https://zhuikoavi.github.io/kozyr-web/

1. Откройте ссылку в Safari (нужен интернет только в первый раз).
2. «Поделиться» → «На экран „Домой“» — дальше «Козырь» запускается как приложение, без интернета.
3. «Создать стол» — ваш телефон держит стол; друзья в той же Wi‑Fi сети или на вашей точке доступа
   жмут «Присоединиться» и обмениваются с вами QR-кодами.

Сайт собирается из закрытого репозитория игры (ветка `gh-pages` — готовые файлы, не правьте вручную).
